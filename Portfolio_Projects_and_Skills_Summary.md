## 1. AI-Powered Digital Products & SaaS Applications

### **BlurbSmith**
* **Type:** SaaS Web Application / AI Publishing Product
* **Overview:** An AI-powered SaaS tool built specifically for authors to generate Amazon best-seller style book descriptions using Gemini 2.0 AI and export them seamlessly into Google Docs.
* **Key Features:** Gemini multimodal prompt workflows, real-time formatting preview, Google Docs API integration, Firebase user authentication and saved state.
* **Core Competencies:** SaaS design, AI prompt engineering for publishing, Google Workspace API integration, React & Node.js architecture.

### **Tania Vorster Style Analyst**
* **Type:** AI Writing & Editorial Analysis Web Tool
* **Overview:** An expert line-editing assistant and author style guide generator designed to analyze voice, tone, sentence structure, pacing, and editorial consistency.
* **Key Features:** Automated style fingerprinting, voice-matching editorial recommendations, custom author style guide generation.
* **Core Competencies:** Copy editing expertise, voice analysis, custom AI system prompt engineering, natural language processing for creative writing.

### **Story-Starter**
* **Type:** Full-Stack Creative Writing Tool
* **Overview:** A web application engineered to spark creative narrative ideas, structure plot lines, and help authors overcome blank-page syndrome.
* **Key Features:** Next.js framework with Cloudflare D1 database storage, prompt generation algorithms, dynamic narrative flow.
* **Core Competencies:** Creative writing frameworks, modern web development (Next.js/Cloudflare Edge), user onboarding UX.

## 2. Business Automation, Audit & Strategy Tools

### **Time & Energy Audit Tool**
* **Type:** Interactive Business Operations & Coaching Lead Magnet
* **Overview:** A guided web application inspired by Dan Martell’s *Buyback Principle*, built for coaching and consultancy business owners to audit daily tasks and categorize them into **Keep**, **Delegate**, or **Automate**.
* **Key Features:**
  * Dynamic visual reporting using Chart.js dashboards.
  * Instant personalized PDF audit downloads using jsPDF.
  * GoHighLevel CRM integration (contacts, custom fields, tags, email sequences, calendar & Stripe payment gates).
  * Webhook automation powered by n8n Cloud.
* **Core Competencies:** Operational workflow optimization, marketing funnel architecture, CRM integration, automated document generation.

### **Series Media GBP Diagnostic Tool**
